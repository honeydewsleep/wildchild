Blower Counter Screens

What each pillow-blower station shows on its 2.8-inch touch screen, drawn from the same layout the firmware uses (320 × 240 pixels, shown at 2×). Below the screen sit the three panel buttons: +  −  BATCH.

What is exact and what is approximate. Positions, sizes, colours and button areas match ui.cpp pixel for pixel. The display's built-in bitmap fonts are approximated with Roboto here; the real text is a touch blockier. Names and pillow types come from the Config tab of the Google Sheet, so the pickers show whatever you type there. The green dot in the header means the sheet link is up; it becomes OFFLINE 3 with the number of un-sent clicks when Wi-Fi drops, and those upload later in order.
